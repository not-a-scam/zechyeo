# plslorr Catalogue Website

> A catalogue website to allow users to see what is in stock and create an order summary for easier processesing for the shop owner

## Overview

This project was a simple front-end only website that was designed to help @plslorr with order summaries. It would show all available items and allow users to add them to cart to generate a "receipt" that they would send to @plslorr to confirm their order and make payment.

This was a small project that I took for fun 

## Requirements

- Streamline ordering format and customer experience
- Ensure the website doesn't incurr any cost
- As much interactivity as possible
- Make it stylistically consistent with the stickers and original catalogue

## Solution

- Create a stylised front-end only website that allows users to add items to cart
- Once items are added, users can generate an image with order summary that they can then send to @plslorr on instagram

## My Role

- Role: Solo Developer
- Team: Solo
- Timeline: 48 hrs

## Key Features

1. **Receipt Printer**: Creates the final order summary to help streamline ordering process
2. **Cart**: Lets user track what they want to buy
3. **Animations**: Minor animations added when hovering and for receipt printing, gives customer a visual response and keeps engagement high
4. **Discount Management**: Allows shop owner to set certain bundle discounts
